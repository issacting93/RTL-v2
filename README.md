# Research Tool Library (RTL) 🔬

Welcome to the **Research Tool Library**, a modular toolkit for high-fidelity conversation analysis and qualitative research.

Built for the **COPHEE Research Lab** at New York University.

## 🔗 Repository
Primary Remote: [https://github.com/cophee-lab/research-tools.git](https://github.com/cophee-lab/research-tools.git)

## 🚀 Quick Start

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Starts the sample dashboard (v2.0) at `http://localhost:5178/`.

## 📂 Project Structure
- **`@research-tools/core`**: Transition matrices, segment logic, and conversation metrics.
- **`@research-tools/ui`**: Premium glassmorphism design system (10+ components).
- **`@research-tools/viz`**: Advanced D3 visualizations (Flows, Portraits, Radials).
- **`@research-tools/sample-app`**: Full-featured 4-tab research dashboard.
